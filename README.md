# 小蓝书（xiaolanshu）

一个类似小红书的社交笔记网站，支持瀑布流内容浏览、用户互动、即时消息和群组聊天。

## 主要功能

- **瀑布流 Feed**：浏览用户发布的图文笔记
- **笔记详情**：查看笔记内容、图片、作者信息
- **用户系统**：注册、登录、个人资料编辑、头像上传
- **互动功能**：点赞、收藏、评论、关注
- **消息与聊天**：私聊、群聊、好友请求、删除好友
- **群组管理**：创建群组、邀请成员、踢人、转让群主、退出群组
- **后台管理**：管理员仪表盘、用户管理、内容审核
